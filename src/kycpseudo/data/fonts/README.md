# Bundled fonts

`OCRB.otf` is the OCR-B typeface that ICAO 9303 prescribes for the machine-readable
zone of passports. It is bundled so the MRZ is drawn in the same face on every host.

- Outlines: Matthew Skala's OCR fonts, version 0.3 (https://tsukurimashou.osdn.jp/ocr.php),
  taken from the Debian package `fonts-ocr-b`.
- Licence: public domain (Matthew Skala, 2012), based on METAFONT sources by
